1. **Executive Takeaway (`takeaway`)**: Diagnose the exact hidden leak costing the reader money/time.
2. **Visual Core Framework (`framework`)**: A named 3-to-4 step mechanism (rendered automatically as a visual System Architecture Diagram on Page 2 of the PDF).

4. **7-Day Action Checklist (`checklist`)**: Printable `[ ]` boxes removing all guesswork.
5. **Whop / Offer Bridge Page (`offer-callout`)**: Natural next step linking directly to the account's Whop offer URL with clear Hormozi Value Equation positioning.
