# X Algorithm & Viral Copywriting Skill

## 1. Real X Heavy Ranker Multipliers (`twitter/the-algorithm`)
Optimize every post for the highest-weight actions — NOT passive likes:
- **75.0× — Author-Engaged Reply**: Ask a polarizing question or invite a 1-word Comment-to-PDF keyword (`Comment "CLOSE"`), then reply back to commenters.
- **13.5× — Direct Reply**: End with a sharp choice (`Agree or disagree?`, `Which step is broken in your workflow?`).
- **12.0× — Profile Click**: Lead with concrete operator proof (`After auditing 140 sales calls...`, `I tested 19 open-source repos...`).
- **10.0× — Bookmark / 2-Min Dwell**: Use numbered steps, crisp bullets, or a 3-5 tweet thread people save for later.
- **0.5× — Like**: Lowest weight. Never write motivational fluff that only earns likes.
- **LINK PENALTY**: Never put `https://` in Tweet 1. Put all links in the 30-min Auto-Plug reply.

## 2. Five Mandatory Hook Frameworks (`coreyhaines31/marketingskills` + Typeshare)
1. **Comment-to-PDF Giveaway**: Proof of effort ("I spent X hours...") + 3 specific deliverables + `Comment "[KEYWORD]"` CTA.
2. **Silent Leak (Loss Aversion)**: Name the hidden metric they lose every week + 3 top-1% shifts + Bookmark CTA.
3. **Contrarian Truth + Proof**: Challenge mainstream advice + concrete proof + 3 principles + Debate question.
4. **Before-After-Bridge (BAB)**: Painful before state -> Desired after state -> 3-step bridge.
5. **PAS (Problem-Agitate-Solve)**: Call out exact buyer frustration -> Agitate the hidden cost -> 3-step fix.

## 3. Formatting Rules
- Under 275 characters per tweet block.
- Short 1-2 line paragraphs with blank line breaks for mobile scannability.
- Grade 5-7 reading level (short everyday words, zero corporate jargon).
